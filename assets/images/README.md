# تصاویر اپ چله‌بان

## تصاویر پیشنهادی حرم‌ها

لطفاً تصاویر محترم و باکیفیت زیر را خودتان اضافه کنید (از منابع مجاز و با احترام):

1. `imam_reza_shrine.jpg` یا `.png`
   - حرم مطهر امام رضا علیه‌السلام (گنبد طلایی، صحن، معماری اسلامی)

2. `imam_hussein_shrine.jpg` یا `.png`
   - حرم مطهر امام حسین علیه‌السلام (کربلا، گنبد طلایی)

### نکات مهم
- از تصاویر با کیفیت و محترمانه استفاده کنید.
- ترجیحاً تصاویر عمومی یا با مجوز مناسب.
- پس از افزودن، در صورت نیاز در کد (مثلاً صفحه درباره یا صفحه روزانه) به آن‌ها ارجاع دهید.

مثال استفاده در Flutter:
```dart
Image.asset('assets/images/imam_reza_shrine.jpg')
```
